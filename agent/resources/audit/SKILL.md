# 静态审计

寻找在当前输入与现实部署条件下可用的危险反序列化链。扫描候选只是线索，少量证据充分的发现比推测链清单有用。不执行目标、payload 或反序列化输入。

用 `skill_read` 按需读取：

- `scan`：定范围、找入口与危险能力、筛选候选，避免重复全图展开。
- `explore`：查字节码、实际分派、值来源和连接支持；预算与前沿续查。
- `verify`：标记 `success` 前必读；核对可控输入、触发、完整绑定、危险影响和现实条件。
- `board`：保存关键判断、已查范围、证据和下一步，压缩或恢复后续接。
- `report`：结束探索后读取，只报告通过核查的风险，明确剩余范围。

自行选择工具、知识、方向和查询量，不设固定调用次数或必须跑完的流程。默认预算控制一次查询的工作量，不是探索总额；依据剩余前沿和证据价值继续。关键判断改变时更新黑板，用户纠偏后调整方向。
决定收尾时调用 `audit_phase` 并说明已查范围、结果与停止原因；未解决问题可保留，但不能因截断或未找到而宣称安全。需要补查时恢复探索。
